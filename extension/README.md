# Ocean for Chrome

Ocean in Chrome's side panel: chat, read the page you are on, fill forms, and click or type on pages with your approval.

## Install (once)
1. Unzip `ocean-extension.zip` into a folder you will keep, for example `Documents\Ocean\extension`. Chrome loads it from there, so do not delete the folder.
2. In Chrome, go to `chrome://extensions`.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and choose the unzipped folder.
5. Pin Ocean: click the puzzle icon by the address bar, then the pin next to Ocean.

## Connect (once)
1. Open Ocean on the web, click **Settings** at the bottom of the chat list, then **Connect Chrome extension**.
2. Click the Ocean icon in Chrome (or press Alt+O) and type the code.

## Use
- **Page** on: your message goes with the page you are looking at.
- **Act** on: Ocean may click, type and fill forms. It asks you before anything that sends, submits, saves, pays or deletes, and never types passwords, card or ID numbers.
- Right-click selected text and choose **Ask Ocean about** to ask about it.
- Stop a task at any time with the square button.

## Remove access
In Ocean on the web: Settings, Connected devices, Remove.
